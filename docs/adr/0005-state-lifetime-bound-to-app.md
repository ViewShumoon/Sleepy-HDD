# 磁盘的休眠/离线状态仅存在于本软件运行期间

磁盘离线属性是持久的（重启后依然离线），而软件开机自启默认关闭，两者会冲突（离线盘重启后无人上线）。决策：把磁盘状态与软件生命周期绑定——(a) 软件正常退出时自动将本软件置为休眠/离线的磁盘全部唤醒；(b) 软件启动时扫描状态文件（按磁盘序列号/唯一 ID 匹配，而非重启后可能变化的盘号），把记录在案且仍离线的盘重新上线，作为崩溃/被强杀的兜底。由此"开机后硬盘恢复正常状态"由 (a)+(b) 组合保证，无需额外机制。

Considered options: 状态跨重启持久 + 强制开机自启（被否：自启默认关是用户诉求）；不管重启后果（被否：用户会锁死自己的盘）。

Consequences: 只要软件没在运行，磁盘必然处于在线状态。已知副作用：用户手动用 diskpart 离线过、且恰好在软件状态记录里的磁盘，会在软件启动时被误上线——接受。
